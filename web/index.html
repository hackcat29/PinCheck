How it works

  1. 01

    Pin

    List the circuits your app calls.

  2. 02

    Compare

    Evaluate every input of both circuits at one block.

  3. 03

    Replay

    Send the first difference to both deployed processors.

  4. 04

    Gate

    Block the merge, or record an intended change.

What a pass means

  • Same output bits for every input
  • Read at one pinned block hash
  • Under TAP-02 evaluation semantics
  • Confirmed against the deployed processors
  • That either circuit is correct
  • What the bits mean to your app
  • Behavior after an implementation upgrade
  • Stateful circuits that are not identical
