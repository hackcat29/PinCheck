Catch breaking TapeOut circuit upgrades before they ship.

Pin the circuits your app calls. When a pull request proposes a new one, PinCheck checks every input at one X Layer block, replays the first difference on the deployed processors, and fails the check with the input that proves it.

How PinCheck works

  1. Pin

    List the circuits your app calls in pincheck.json, as processor address and circuit ID.

  2. Compare

    Every input of both circuits is evaluated at one block hash: all 2n inputs, up to 26 input bits in CI.

  3. Replay

    The first difference is sent to both deployed processors with eval. If a processor disagrees with PinCheck, the check fails.

  4. Gate

    A required GitHub check blocks the merge. An intended change is approved in the manifest, with a reason.
